User: Explain how a hash map differs from a binary search tree.
Assistant: A hash map stores key-value pairs in buckets chosen by a hash
function, so typical lookup is constant time. A binary search tree keeps
keys ordered, so lookup is logarithmic and you can iterate in sorted
order. Hash maps need a good hash and can clash; trees stay ordered but
need balancing (AVL, red-black) to avoid degenerating into a list.

User: Write a Python function that merges two sorted lists.
Assistant: def merge_sorted(a, b):
    i = j = 0
    out = []
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            out.append(a[i]); i += 1
        else:
            out.append(b[j]); j += 1
    out.extend(a[i:])
    out.extend(b[j:])
    return out

User: Why does speculative decoding help?
